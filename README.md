# Сетевой планировщик

Многопользовательский WPF-планировщик задач для Windows 10/11. Несколько экземпляров приложения на разных ПК работают с общей сетевой папкой SMB и единым SQLite-файлом через общий эксклюзивный `planner.lock`.

## Сборка

Требуется .NET 8 SDK с Windows Desktop workload.

```powershell
.\build.ps1
```

Публикация автономной Windows-сборки:

```powershell
.\publish.ps1 -Runtime win-x64
```

Готовая папка появится в `publish\win-x64`.

## Настройка сетевой папки

Файл `planner.settings.json` автоматически копируется рядом с `Сетевой планировщик.exe`. Путь можно менять после публикации без пересборки.

Пример:

```json
{
  "SharedFolder": "\\\\FILESERV01\\Planner$\\Tasks",
  "DatabaseFileName": "planner.db",
  "LockFileName": "planner.lock",
  "SignalsFolderName": "Signals",
  "TimeZoneId": "",
  "DatabaseLockTimeoutSeconds": 10,
  "FallbackSyncSeconds": 30,
  "CronPollSeconds": 60,
  "ReminderPollSeconds": 30,
  "SnapMinutes": 30,
  "RecurrenceHorizonMonths": 12,
  "UpdateFolder": "\\\\FILESERV01\\Planner$\\Update",
  "UpdateManifestFileName": "update.json",
  "CheckUpdatesOnStartup": true,
  "CalendarHourHeight": 48
}
```

Все пользователи должны иметь права чтения/записи/создания/изменения/удаления в этой общей папке.

Настройки читаются двумя слоями: файл рядом с программой задаёт значения по умолчанию для всего отдела, а личный файл пользователя `%LOCALAPPDATA%\NetworkPlanner\planner.settings.json` перекрывает изменённые параметры. Окно **⚙ Настройки** пишет именно в личный файл, поэтому программа может быть установлена в папку, доступную только на чтение.

## Пользователи

Первый Windows-пользователь, открывший пустую базу, создаётся как администратор. После этого администратор добавляет остальных сотрудников. Поле **Учётная запись Windows** должно совпадать с `Environment.UserName` на ПК сотрудника.

Иерархия задаётся полем руководителя. Обычный пользователь видит себя и своих подчинённых любого уровня. Подчинённый не получает доступ к собственным задачам руководителя.

## Права на задачи

- Создатель задачи и администратор могут полностью редактировать, переносить, передавать и удалять задачу.
- Исполнитель чужой задачи может менять только описание/ход выполнения и статус.
- Руководитель может назначать и передавать задачи только себе или своим подчинённым; передача из контекстного меню предлагает подчинённых.
- Задачу можно удалить только её создателю или администратору.

## Дата и время

Дата обязательна для каждой задачи. Время может отсутствовать. Такая задача хранится с датой и признаком `IsAllDay=1`, а в режимах **День** и **Рабочая неделя** отображается в верхней полосе **Без времени** над почасовой сеткой.

При миграции старой базы записи с `StartDate IS NULL` получают текущую дату и признак «без времени», чтобы не исчезнуть из календаря.

## Повторение

Поддерживаются:

- ежедневно;
- по будням;
- еженедельно;
- ежемесячно;
- ежеквартально;
- раз в полугодие;
- ежегодно;
- произвольное расписание в формате Unix cron или Quartz.

### Форматы расписания

Формат определяется числом полей.

| Полей | Формат | Поля |
| --- | --- | --- |
| 5 | Unix cron | минуты, часы, день месяца, месяц, день недели (0 и 7 — воскресенье) |
| 6–7 | Quartz | секунды, минуты, часы, день месяца, месяц, день недели (1 — воскресенье, 7 — суббота), необязательный год |

В формате Quartz поддерживаются `?` (поле дня не задано), `L` (последний день месяца или последний такой день недели), `W` (ближайший будний день) и `#` (n-й день недели в месяце). Поле года должно быть `*` или `?`: конкретный год не поддерживается.

Примеры Quartz: `0 0 9 ? * 2-6` — по будням в 09:00; `0 0 9 L * ?` — в последний день месяца в 09:00; `0 15 10 ? * 6#3` — каждую третью пятницу месяца в 10:15.

Под полем расписания программа показывает разобранное выражение обычными словами либо текст ошибки, поэтому опечатку видно сразу.

### Автоперенос с выходных

Флажок **Автоперенос с выходных на будний день** в карточке задачи включается для повторяющихся задач. Повтор, выпавший на субботу или воскресенье, переносится на ближайший будний день **перед** выходными — работу лучше сделать заранее. Если этот день уже прошёл (перенос должен быть строго позже сегодняшнего дня), берётся ближайший будний день **после** выходных. Время начала сохраняется.

Отдельно от этого при сохранении задачи с датой на субботу или воскресенье программа предупреждает об этом и предлагает конкретную дату ближайшего буднего дня. Предложение можно принять, отклонить или вернуться к редактированию.

Шаблон повторения хранится отдельно. Физические экземпляры формируются сразу вперёд на `RecurrenceHorizonMonths` месяцев (по умолчанию 12). `RecurrenceExecutions` защищает от дублей, если одновременно запущено несколько ПК.

## Интерфейс

- День / Рабочая неделя / Месяц. Активный режим подсвечен.
- В режиме месяца сверху отображается название текущего месяца и года.
- Двойной щелчок по задаче открывает её в любом представлении; одиночный щелчок только выделяет. Двойной щелчок по свободному месту сетки создаёт задачу на это время.
- ПКМ по задаче: открыть, изменить статус, передать (для создателя/администратора), удалить (для создателя/администратора).
- Перетаскивание задачи в часовую сетку округляет время по `SnapMinutes`.
- **Ctrl + колесо мыши** меняет масштаб часовой сетки: высота часа растягивается от 20 до 220 пикселей. Время под указателем остаётся на месте. Выбранный масштаб сохраняется между запусками.
- **Просроченные задачи со вчера и ранее дублируются в верхней полосе текущего дня** и помечены значком «⚠» и датой исходного срока. Исходная карточка остаётся на своём дне. В контекстном меню дубликата есть команда «Перенести на сегодня». Задачи, просроченные сегодня, показываются как раньше — на своём месте в сетке.
- В колонке сегодняшнего дня показана красная линия текущего времени, а сетка при открытии сразу прокручена к рабочим часам.
- Слева показываются сотрудники и шаблоны повторяющихся задач.
- Поиск в верхней панели фильтрует задачи по названию, описанию, исполнителю и автору; флажок «Скрыть выполненные» убирает закрытые задачи. Фильтрация выполняется локально и не нагружает сетевую базу.
- Внизу слева — время последнего обновления, по центру — версия программы, справа — текущий пользователь.
- Кнопка **⚙ Настройки** открывает свойства программы, пути к сетевым папкам и проверку обновлений.

## Статистика для руководителя

Кнопка **📊 Статистика** открывает отчёт по задачам за период.

- Строка на каждого сотрудника, доступного текущему пользователю: руководитель видит себя и подчинённых любого уровня, администратор — всех.
- Итоговая строка «Итого» и карточки сверху дают общую картину: всего, выполнено, в работе, ожидает, просрочено и доля выполненных.
- Колонки: всего задач, по статусам, просрочено, процент выполнения, «Свои» (сотрудник поставил задачу сам) и «Поручено» (задачу поставил кто-то другой).
- Периоды: текущая неделя, месяц, квартал, год или произвольный интервал двумя календарями.
- Кнопка **Экспорт в CSV** сохраняет отчёт с разделителем `;` в кодировке UTF-8 с BOM — файл открывается в Excel без мастера импорта.
- Просрочка считается тем же правилом, что и цвет карточки в календаре, поэтому отчёт и календарь всегда согласованы. Шаблоны повторения в отчёт не входят — считаются только реальные экземпляры задач.


## Настройки и свойства программы

Кнопка **⚙ Настройки** в верхней панели открывает одно окно с четырьмя разделами.

- **Свойства программы** — название, версия, дата сборки, папка установки, путь к личному файлу настроек и путь к журналу ошибок.
- **Сетевая папка с базой** — путь к общей папке, имя файла базы и имя папки сигналов. Путь можно ввести вручную или выбрать кнопкой **Обзор…**. После смены расположения базы программу нужно перезапустить, о чём выводится сообщение.
- **Обновления** — сетевая папка с новыми версиями, имя файла описания версии, флажок проверки при запуске и кнопки **Проверить обновления** и **Установить и перезапустить**.
- **Календарь** — шаг сетки `SnapMinutes` и горизонт создания повторов в месяцах.

Значения проверяются при сохранении: ошибочный путь или недопустимый шаг сетки не будут записаны. Если при запуске путь к базе не настроен, программа не закрывается молча, а предлагает сразу открыть это окно.

## Автообновление из сетевой папки

Программа обновляется из ZIP-архива, выложенного в сетевую папку.

### Что лежит в папке обновлений

```
\\FILESERV01\Planner$\Update\
    update.json
    Планировщик-1.1.0-win-x64.zip
```

`update.json` — небольшой файл описания версии:

```json
{
  "Version": "1.1.0",
  "File": "Планировщик-1.1.0-win-x64.zip",
  "ReleasedAt": "2026-09-09T12:00:00",
  "Notes": "Масштаб сетки, Quartz cron, автообновление"
}
```

Проверка обновления читает **только этот файл** и не открывает архив, поэтому занимает доли секунды и не мешает работе. Если `update.json` отсутствует, программа разбирает имена ZIP-архивов в папке и берёт наибольшую версию — это тоже лишь перечисление каталога. У проверки есть срок в 10 секунд: недоступная сетевая папка не подвешивает программу.

При включённом флажке проверка выполняется в фоне при запуске. Найденная версия показывается в строке состояния и в уведомлении Windows; сама установка запускается только вручную.

### Как выложить новую версию

```powershell
.\publish.ps1 -Runtime win-x64 -UpdateFolder "\\FILESERV01\Planner$\Update" -Notes "Что нового"
```

Скрипт публикует сборку, собирает архив, формирует `update.json` и копирует оба файла в папку обновлений. `update.json` копируется последним, поэтому до окончания выкладки клиенты продолжают видеть прежнюю версию.

### Как устанавливается обновление

Работающая программа не может заменить собственные файлы, поэтому установку выполняет отдельный сценарий-обновлятель.

1. Архив копируется в `%LOCALAPPDATA%\NetworkPlanner\update\download`.
2. Программа распаковывает его в `…\update\staging` и проверяет, что внутри есть `Сетевой планировщик.exe`. Архив может содержать файлы как в корне, так и в единственной вложенной папке.
3. Создаётся и запускается сценарий `…\update\apply-update.ps1`, после чего программа закрывается.
4. Сценарий дожидается выхода программы, копирует файлы поверх установленной версии через `robocopy` (с повторными попытками, если файл ещё занят) и запускает программу заново.

Файл `planner.settings.json` рядом с программой при обновлении не перезаписывается — настроенные администратором пути сохраняются. Ход установки записывается в `%LOCALAPPDATA%\NetworkPlanner\update\update.log`.

## Русский интерфейс

Приложение принудительно использует культуру `ru-RU` как для .NET, так и для WPF. Поэтому названия дней недели и месяцев в режимах **День**, **Рабочая неделя** и **Месяц** выводятся на русском независимо от языка интерфейса Windows.

## Системные уведомления Windows

Напоминания и сообщения о назначенных задачах отправляются через штатный центр уведомлений Windows (`AppNotificationManager`, Windows App SDK). Собственное всплывающее WPF-окно уведомлений удалено. При нажатии на уведомление открывается/активируется окно «Сетевого планировщика».

Для приложения используется собственная сгенерированная иконка. Она встроена в EXE, отображается в окнах и регистрируется для системных уведомлений Windows.

## Сетевой доступ к SQLite

WAL не используется. Перед каждым чтением или записью экземпляр приложения эксклюзивно открывает общий `planner.lock` через `FileShare.None`, затем открывает SQLite, выполняет короткую операцию и закрывает соединение до освобождения lock.

`FileSystemWatcher` в папке `Signals` ускоряет обновления между ПК, а периодическая синхронизация является резервным механизмом.

## Управление календарём в стиле Google Calendar

В версии 5 добавлено более прямое взаимодействие с сеткой календаря:

- Делегированная задача не исчезает из собственного календаря руководителя. Одна запись `Tasks` отображается и создателю (`CreatedByUserId`), и назначенному исполнителю (`AssignedToUserId`). На карточке видны исполнитель и текущий статус.
- Двойной щелчок по временной сетке в режимах «День» и «Рабочая неделя» открывает создание задачи с уже выбранными датой и временем.
- Длительность новой задачи при двойном щелчке выбирается в верхней панели: 15, 30, 45, 60, 90 или 120 минут.
- Создатель задачи или администратор может изменить длительность, потянув нижний маркер карточки. Длительность округляется по `SnapMinutes`.
- Во время переноса показывается полупрозрачная копия карточки под мышью и подсветка будущего положения в сетке. После отпускания новое время записывается в общую БД.
- Исполнитель чужой задачи не может перетаскивать или растягивать её, но может менять статус и описание хода выполнения.


## Изменения версии 6

- Иконка заменена на более минималистичную: календарь + командная сеть без лишнего текста и мелких деталей. PNG используется системными уведомлениями Windows, ICO — EXE и окнами WPF.
- Карточки задач в режимах «День» и «Рабочая неделя» автоматически увеличивают визуальную высоту, если фактической длительности мало для полного текста. Реальная длительность задачи при этом не меняется.
- Заголовок и служебный текст карточки переносятся по словам без `CharacterEllipsis`.
- Изменение длительности стало проще: нижняя зона захвата имеет высоту 22 px и занимает всю ширину карточки. Во время растягивания показывается текущая длительность и тонкая линия фактического конца задачи.
- Цвета задач зависят от состояния:
  - зелёный — **В работе**;
  - синий — **Ожидает выполнения**;
  - красный — **Просрочено**;
  - серый — **Выполнено**.
- Просрочка вычисляется автоматически. Для задачи со временем используется момент окончания, для задачи без времени — завершение даты. Выполненная задача всегда остаётся серой.
- Та же цветовая схема применяется в месячном представлении и в верхней полосе задач без времени.


## Изменения версии 7

- Задача открывается **двойным щелчком** во всех представлениях. Раньше в режиме «Месяц» задача открывалась одиночным щелчком, а в сетке дня и недели двойной щелчок иногда терялся из-за начатого перетаскивания. Теперь двойной щелчок обрабатывается до старта перетаскивания, а окно задачи открывается после завершения обработки мыши.
- Добавлена **статистика по подчинённым и общая** с периодами, процентом выполнения, подсчётом просрочки и экспортом в CSV.
- Добавлены поиск по задачам и фильтр «Скрыть выполненные».
- Добавлены горячие клавиши и подсветка активного режима календаря.
- В сетке дня и недели появилась линия текущего времени; при открытии календарь прокручивается к рабочим часам, а не к 00:00.
- Расписание повторения показывается словами («по будням в 09:00») вместо сырого Cron-выражения. Поле Cron доступно только при выборе режима «Cron», день недели — только при «Еженедельно».
- У экземпляра повторяющейся задачи расписание больше не редактируется: оно меняется в шаблоне, о чём сообщает подсказка в окне задачи.
- Передать задачу теперь можно и себе — руководитель может забрать делегированную задачу обратно.
- Ошибки операций показываются модальным окном, а не только системным уведомлением: если центр уведомлений Windows отключён политикой, пользователь всё равно видит причину.
- Непредвиденные ошибки больше не закрывают приложение молча: они записываются в журнал `%LOCALAPPDATA%\NetworkPlanner\planner.log` и показываются пользователю.
- Свои же действия не возвращаются пользователю уведомлением.
- Напоминания не приходят по уже выполненным задачам.
- В режиме «Месяц» день с большим числом задач прокручивается, сегодняшний день подсвечен, дни соседних месяцев приглушены, на карточке видно время задачи.
- Кнопки «Открыть задачу» и «Редактировать» отключаются, когда ничего не выбрано; двойной щелчок в списке пользователей открывает карточку сотрудника.

## Изменения версии 8

- **Масштаб часовой сетки по `Ctrl` + колесо мыши.** Высота часа меняется от 20 до 220 пикселей, время под указателем остаётся на месте, а при сильном уменьшении подписи часов прореживаются, чтобы не сливаться. Выбранный масштаб сохраняется между запусками.
- **Просроченные задачи со вчера и ранее дублируются в текущем дне** — в верхней полосе календаря и первыми в ячейке сегодняшнего дня в режиме «Месяц». Дубликат помечен значком «⚠» и датой исходного срока, а в его контекстном меню есть команда «Перенести на сегодня». Исходная карточка остаётся на своём дне. Задачи, просроченные сегодня, отображаются как раньше.
- **Поддержка Quartz cron.** Расписание из шести-семи полей читается по правилам Quartz: секунды, нумерация дней недели с воскресенья-единицы, `?`, `L`, `W` и `#`. Пятипольные выражения по-прежнему читаются как Unix cron. Разбор един для проверки в карточке задачи и для генерации повторов.
- **Автоперенос повторов с выходных на будний день** — по флажку в карточке задачи. Выбирается ближайший будний день перед выходными, а если он уже прошёл — ближайший будний день после.
- **Предупреждение при назначении задачи на выходной** с предложением конкретной даты ближайшего буднего дня. От переноса можно отказаться. Предупреждение показывается только при назначении новой даты, а не при каждом сохранении.
- **Кнопка «⚙ Настройки»** — свойства программы с версией и датой сборки, сетевой путь к папке с базой, папка обновлений и параметры календаря. Настройки сохраняются в личный файл пользователя, поэтому программа может быть установлена в папку только для чтения.
- **Автообновление из ZIP-архива в сетевой папке.** Проверка читает небольшой файл `update.json` и потому выполняется мгновенно; установку выполняет отдельный сценарий-обновлятель, который дожидается выхода программы, заменяет файлы и запускает её заново. `publish.ps1` собирает архив и манифест и умеет сразу выкладывать их в сетевую папку.
- **Убраны лишние подсказки** про двойной щелчок в строке состояния, всплывающих подсказках календаря и режима «Месяц», списке шаблонов и карточке задачи. Вместо подсказки в строке состояния выводится версия программы.

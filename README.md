# Task Planner

Веб-планировщик задач в стиле [Super Productivity](https://app.super-productivity.com), но с **синхронизацией между пользователями**, **регулярными задачами**, гибкими напоминаниями (в том числе при закрытой вкладке) и авторизацией. Разворачивается в локальной сети организации **без домена**, одним кликом на Windows.

## Возможности

- Пользователи и авторизация (JWT). Первый зарегистрированный — администратор.
- Проекты с назначением участников — задачи проекта видят все его участники (общие задачи).
- Задачи: заголовок, заметки, исполнитель, приоритет, оценка, срок, порядок.
- Регулярные задачи: ежедневно / по будням / каждые N дней / недель / месяцев; выбор дней недели.
- Напоминания за произвольное время (минуты / часы / дни / недели), с автоматическим сдвигом на ближайший **рабочий день**, если попадает на выходной.
- Пропущенные напоминания — при входе выводятся отдельным списком с подтверждением.
- Уведомления при **закрытой вкладке** через Web Push + Service Worker.
- Живая синхронизация правок между пользователями через WebSocket.
- Тёмный дизайн, аккуратные карточки задач, боковая панель проектов.
- Одна SQLite-база — нет внешних сервисов, ничего дополнительно ставить не нужно.

## Требования

- **Windows** (или Linux) c Python **3.11+**. На Windows поставьте с [python.org](https://www.python.org/downloads/), обязательно отметьте «Add python to PATH».

## Запуск на Windows (проще некуда)

1. Скопируйте папку проекта на сервер (любую машину в локальной сети).
2. Дважды кликните `install.bat`. Он создаст venv, поставит зависимости и сгенерирует self-signed сертификат.
3. Дважды кликните `run.bat`. Приложение поднимется на `https://<адрес-этой-машины>:8443`.
4. (Опционально) Дважды кликните `install_service.bat` — приложение будет запускаться при входе в Windows.
5. Откройте `firewall`: разрешите входящие подключения на TCP 8443 (или через диалог Windows при первом запуске).

**Первый вход:** откройте `https://<IP>:8443`, нажмите «Регистрация» — вы станете администратором. Остальные пользователи регистрируются оттуда же.

### Про сертификат (важно)

Web Push и Service Worker работают **только по HTTPS**. Скрипт `make_cert.py` создаёт сертификат, действительный для `localhost`, IP этой машины и (по желанию) любых имён из аргументов:

```
python scripts/make_cert.py 192.168.1.10 planner.local
```

Чтобы браузеры не жаловались и разрешали пуш-уведомления, **установите `data/cert.pem` в «Доверенные корневые центры сертификации»** на каждом клиентском компьютере:

- Windows (для всей машины): двойной клик по `cert.pem` → «Установить сертификат» → «Локальный компьютер» → «Поместить все сертификаты в … Доверенные корневые центры сертификации».
- Windows (только для пользователя): аналогично, «Текущий пользователь».
- Chrome/Edge подхватят системное хранилище автоматически.
- Firefox: `about:preferences#privacy` → «Просмотр сертификатов» → «Центры сертификации» → импортировать `cert.pem`.

Групповая политика (GPO) может распространить сертификат по всем ПК разом.

## Запуск на Linux

```bash
./run.sh
```

Он сам создаст venv и сертификат при первом старте.

## Порт по умолчанию

`8443`. Можно переопределить: `set PORT=9000 && run.bat` (Windows) или `PORT=9000 ./run.sh` (Linux).

## Настройка

Параметры настраиваются через переменные окружения или файл `.env` в корне:

```
SECRET_KEY=<длинная случайная строка>
ACCESS_TOKEN_TTL_MINUTES=10080
VAPID_SUBJECT=mailto:admin@local
SCHEDULER_TICK_SECONDS=20
```

`SECRET_KEY` **обязательно** смените в проде — по нему подписываются JWT.

## Данные

- `data/app.db` — база данных (SQLite).
- `data/vapid_*.pem` — ключи для Web Push (не удалять — подписки на клиентах привязаны к паблику).
- `data/cert.pem`, `data/key.pem` — TLS.

Бэкап — просто скопировать папку `data/`.

## Обновление

Замените код (кроме папки `data/`), запустите `install.bat` ещё раз (обновит зависимости), затем `run.bat`.

## Технологии

- FastAPI + SQLModel + SQLite + APScheduler
- JWT (python-jose) + bcrypt (passlib)
- Web Push (pywebpush, VAPID)
- WebSocket для живой синхронизации
- Ванильный JS + собственный CSS (без CDN, работает офлайн-в-локалке)

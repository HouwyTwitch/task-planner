# Проверка версии 6

В текущей Linux-среде отсутствует .NET / Windows Desktop SDK, поэтому реальный `dotnet build` WPF-проекта здесь выполнить невозможно. Выполнены доступные статические проверки.

## Пройдено

- XML-проверка всех XAML, `.csproj` и `app.manifest` — успешно.
- JSON-проверка `planner.settings.json` — успешно.
- Проверка парных скобок/кавычек C# с игнорированием строк и комментариев — успешно для всех C#-файлов.
- Проверка обработчиков событий XAML против code-behind — отсутствующих обработчиков не найдено.
- Новая иконка сформирована как PNG 512×512 и Windows ICO с размерами 16, 24, 32, 48, 64, 128 и 256 px.
- `ApplicationIcon`, WPF `Window.Icon` и Windows App Notification используют `Assets/NetworkPlanner.ico` / `Assets/NetworkPlanner.png`.
- В `TaskItem` добавлено вычисляемое состояние `VisualState` с приоритетом: Completed → Overdue → InProgress → Pending.
- В календарной сетке добавлены четыре цветовые схемы и автоматическая красная индикация просрочки.
- Для коротких временных задач отключено усечение текста и добавлено автоматическое увеличение визуальной высоты без изменения `DurationSeconds`.
- Resize-зона увеличена до 22 px на всю ширину карточки; во время операции показываются линия фактического конца и текущая длительность.

## Финальная проверка на Windows

После распаковки выполнить:

```powershell
.\build.ps1
```

Затем:

```powershell
.\publish.ps1 -Runtime win-x64
```
